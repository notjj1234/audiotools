# Findings

- **fnd_1** Moises.app 2.1.0 (Mac) does not split songs on the computer: its Resources folder holds no AI model files, only an Electron app (app.asar), an audio capture add-on (capture.node) and a plugin server helper. Its main code opens Moises's website https://studio.moises.ai inside the window, and the Play tab's 'new project' button points to the web page /upload/split/3. (Seen it; evidence: ev_b4fd2817ad17f5e7c66a9828efed3e504c16e347db6c408f5a09ba634e5f3437, ev_b89304b953b10f6a7fab9d622dab8883d2a27b793ffc57fed30e9de1b8eb710b, ev_834095bd34ef47e2b2296cdf9a2e06ca97120954ebdcdf07ba8525a0c49bc721)
- **fnd_2** Stem separation for Play happens on Moises's servers: the song is uploaded through the hosted web page and the stems come back from the server. The AI method used there cannot be seen from the desktop app. (Best guess; evidence: ev_b89304b953b10f6a7fab9d622dab8883d2a27b793ffc57fed30e9de1b8eb710b, ev_7938bfa785d769fe9ec422dc98bfec1a21f9fdc60f7c5c8df2a277dd001c14b1)
